LinkedIn page (demo)

This local page plays the role of linkedin.com. It loads a simulated reCAPTCHA script from the local Google server on port 5000. The script adds an iframe that triggers a CSP violation.

What to look for in DevTools

Open DevTools (F12), select Console, and reload this page if needed. Expect a message similar to:

Framing 'http://localhost:5000/' violates the following Content Security Policy directive: "frame-ancestors 'self' localhost:5000". The request has been blocked.

This is intentional: the browser blocks the iframe document and sends a CSP report to the collector on port 5000. This page keeps working. The exact message and reported URLs may vary between browsers.

In the Network tab, look for a POST request to /csp/frame-ancestors/tracking_correlation_nonce_….
